**Key Analysis:**

### 3. Customer Churn Analysis & Prediction

A customer analytics and machine learning project analyzing customer churn patterns and predicting customers who are at risk of leaving.

**Tools:** Python (Pandas, Scikit-learn), Google Colab

**Key Analysis:**

- Customer churn exploratory data analysis
- Data cleaning and preprocessing
- Class imbalance handling using SMOTE
- Logistic Regression and Random Forest
- Hyperparameter tuning using GridSearchCV
- Model evaluation and comparison
- Random Forest feature importance
- Customer retention recommendations

[View Project](https://github.com/JaydenKwong/Github-portfolio/tree/main/Machine%20Learning/Customer%20Churn%20Analysis)
