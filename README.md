## Projects

### 1. Global Superstore Sales Performance Dashboard

A sales analytics project using Python and Tableau to analyze sales performance, profitability, product performance, and geographic trends across global markets.

**Tools:** Python (Pandas), Tableau, Google Colab

**Key Analysis:**
- Sales and profit trends
- Product category and sub-category performance
- Market and country performance
- Discount and profitability analysis
- Interactive geographic dashboard

[View Project](Dashboards/Global-Superstore-Sales-Dashboard)

### 2. Customer Segmentation & RFM Analysis Dashboard

A customer analytics project using Python and Tableau to analyze purchasing behaviour and segment customers using Recency, Frequency, and Monetary (RFM) analysis.

**Tools:** Python (Pandas), Tableau, Google Colab

**Key Analysis:**

- Customer-level RFM analysis
- Recency, frequency, and monetary scoring
- Customer segmentation into behavioural groups
- Customer value and purchase frequency analysis
- Interactive customer segment dashboard

[View Project](Dashboards/Customer-Segmentation-RFM-Analysis)

---

### 3. Customer Churn Analysis & Prediction

A customer analytics and machine learning project analyzing customer churn patterns and predicting customers who are at risk of leaving.

**Tools:** Python (Pandas, Scikit-learn), Google Colab

**Key Analysis:**

- Customer churn exploratory data analysis
- Data cleaning and preprocessing
- Class imbalance handling using SMOTE
- Logistic Regression and Random Forest
- Hyperparameter tuning using GridSearchCV
- Model evaluation and comparison
- Random Forest feature importance
- Customer retention recommendations

[View Project](https://github.com/JaydenKwong/Github-portfolio/tree/main/Machine%20Learning/Customer%20Churn%20Analysis)
